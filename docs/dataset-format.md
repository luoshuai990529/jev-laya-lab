# 决策数据集 JSON v1

在实验台的「数据集」入口导入 UTF-8 JSON 文件。导入会创建一个新的本地数据集，不覆盖默认摩托车数据；同一题号可以分别存在于不同数据集。

可复制 [examples/decision-sample.json](../examples/decision-sample.json) 开始编辑。机器可读字段定义见 [examples/dataset.schema.json](../examples/dataset.schema.json)。应用的校验是最终依据：先去掉文本首尾空白，再检查长度和题号唯一性。长度按 JavaScript UTF-16 单元计算，常见汉字为 1、部分 Emoji 为 2；JSON Schema 自身的字符计数与应用检查可能不同。

## 文件结构

```json
{
  "schemaVersion": 1,
  "name": "我的选择测试",
  "instructions": "按照题干给出的业务约束做出选择。",
  "questions": [
    {
      "id": "case-001",
      "type": "single",
      "question": "用户需要重置密码。应转交哪个团队？",
      "options": { "A": "账号支持", "B": "物流支持" },
      "answer": ["A"],
      "category": "客服",
      "explanation": "密码属于账号支持范围。"
    }
  ]
}
```

顶层只允许以下字段，多余字段会导致整个导入失败：

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| `schemaVersion` | 是 | 数字 `1`。 |
| `name` | 是 | 非空字符串，最多 100 单元。 |
| `instructions` | 否 | 字符串，最多 3,000 单元；省略或空白时使用通用选择指令。 |
| `questions` | 是 | 1–10,000 个题目对象。 |

导入请求上限为 **8 MiB（8,388,608 字节）**，按 UTF-8 字节计算；不能用压缩文件、图片或 CSV 代替 JSON。

## 每道题的规则

题目对象只允许以下字段：

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| `id` | 是 | 非空字符串，最多 128 单元；去掉首尾空白后在本数据集中唯一。 |
| `type` | 是 | `single`、`multiple` 或 `boolean`。 |
| `question` | 是 | 非空题干，最多 5,000 单元。 |
| `options` | 是 | 对象，2–7 个选项，键为 A 起始的连续大写字母，如 A/B 或 A/B/C/D；每项为非空字符串，最多 500 单元。 |
| `answer` | 是 | 非空字母数组；字母必须属于本题选项，不允许重复。 |
| `category` | 否 | 非空分类字符串，最多 100 单元；省略时归为「未分类」。 |
| `explanation` | 否 | 解析字符串，可以为空，最多 5,000 单元。 |

`id` 必须是字符串，数字题号需要写成 `"1"`。例如 `" case-1 "` 和 `"case-1"` 会视为重复题号。`type`、选项字母和答案字母不做自动大小写转换。

- **单选 `single`**：`answer` 恰好一个字母，例如 `["B"]`。
- **多选 `multiple`**：`answer` 可以包含一个或多个正确选项，例如 `["A", "C"]`，必须完全选对才能得分。答案数组顺序不影响判分，导入时按字母排序。
- **判断 `boolean`**：选项必须恰好为 `{"A":"正确","B":"错误"}`；答案恰好一个字母。

例如，只有 A/C 两个键会被拒绝，因为缺少 B；答案 `["Z"]`、`["A", "A"]` 会被拒绝。导入不接受 `source`、`source_url`、`image`、`image_local`、`media` 或逐题 `instructions` 等未知字段。当前通用导入只接受纯文字题，业务上下文请写在题干或数据集指令中。

JSON Schema 描述字段、选项数量与答案范围；跨题 `id` 唯一性、规范化后的 UTF-16 长度由应用补充检查。不要只依据编辑器的 Schema 检查判断一定可以导入。

## 指令、输入与本地数据

自定义数据的默认通用指令关注题意、业务约束、否定词和完整选择，不加入摩托车法规。可用数据集 `instructions` 指定共同规则；在实验表单中填写非空补充指令时，会替换数据集默认指令。默认摩托车数据使用道路安全法规与摩托车驾驶知识指令。

模型请求只包括题干、选项、分类及生效指令等测试输入，不包含 `answer`、`explanation` 或默认数据的来源链接。标准答案是你给定的评分依据，应用不独立校验其事实正确性。题干或业务指令中自行写入答案会造成测试信息泄漏，应自行避免。

验证任意一题失败时，整份数据不会保存，也不会改变当前已有数据；错误会标出题目路径，如 `questions[3].answer`。有效导入原子写入 `.local/datasets.json`，重启后仍可选择；导入数据不会自动上传 GitHub。

启动实验后会锁定题目快照和数据集指纹，运行中不允许切换数据集。实验结束后可以选择其他数据集开始新实验，既有历史结果仍按照当时的数据判分。JSON 导出带有这些快照，也包含标准答案、解析及原始模型响应；分享导出时应考虑自己的业务信息范围。
